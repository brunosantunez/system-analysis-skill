# Systems analysis skill for AI

* This includes everything contained in the 'references' folder, along with the text file inside it.
* It is compatible with Codex, Claude, and other AIs.

## Install
To install it, simply drag the folder from the ZIP file downloaded from GitHub into the `.codex/skills/` directory. Once that’s done, it will be available for use in your next session via `$system-analysis-skill`.
